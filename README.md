# Apni-Library

Library Management System (Python + SQLite3)

A simple Library Management System built using Python with a lightweight SQLite3 database for data storage.

Features
300 preloaded book records
Organized book categories:
Education
Technology
Self Help
Fantasy
Fiction
SQLite3 database integration
Easy-to-use and lightweight structure

Tech Stack
Python 
SQLite3 
Database

The project uses a pre-built SQLite script (.sql) to create and populate the books table automatically.

How to Use

Run the SQLite script to create the database:

sqlite3 library.db < library_books_300_sqlite.sql
Run the Python application.
The system will automatically load and manage the book records.

Purpose

This project is built for learning database integration with Python and practicing structured data management in a real-world style application.
